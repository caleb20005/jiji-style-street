# Roadmap — Mavazi fashion store (self-contained, no Shopify)

- [ ] Design system (orange/magenta Kilimall-inspired), fonts, root head metadata
- [ ] Built-in product catalog (sample products + images)
- [ ] Header: search, delivery location selector, cart badge
- [ ] Hero banner carousel
- [ ] Category shortcuts (Dresses, Streetwear, Sneakers, Denim, Under KSh 999) filtering the grid
- [ ] Flash Sale with live countdown, discount badges, stock bars
- [ ] Product grid with KSh pricing, strikethrough, ratings, "sold" counts
- [ ] Trust badges (Cash on Delivery, M-Pesa/Card, easy returns)
- [ ] Product view: size/color, stock urgency, review previews
- [ ] Cart drawer with free delivery progress bar
- [ ] Own checkout flow page (contact, delivery, payment method, order confirmation)
- [ ] Tests for cart rules (free delivery threshold, totals)
- [ ] Order history page ("My orders") listing past orders after checkout
- [ ] Shipment tracking page per order (status timeline: placed → confirmed → dispatched → out for delivery → delivered)
